# PROG209 – Assignment 1: Gradient Theme Studio (Java Swing)

A Java Swing app using JFrame, JPanel, JLabel, ImageIcon, inheritance and constructors,
with buttons that change the label text and the panel background.

## Files
- `SwingAssignment.java` – source code
- `icon.png` – application icon (ImageIcon)
- `wireframe.png` – wireframe (Figma export goes here)
- `PROG209_Assignment1_Style2_Documentation.docx` – documentation

## Run
    javac SwingAssignment.java
    java SwingAssignment
(Run from the folder that contains `icon.png`.)
